# Responsive — voir le Skill dédié `responsive-design`

Le détail complet des règles responsive (mobile first, breakpoints, layout, overflow,
interactions tactiles, typographie, composants, tests multi-tailles) a été déplacé vers le Skill
dédié `.claude/skills/responsive-design/SKILL.md` et ses `references/` — c'est la source de
vérité pour tout ce qui concerne l'adaptation aux différentes tailles d'écran.

Ce Skill `ui-ux` reste responsable des règles générales de DA, accessibilité, usabilité et
interaction ; `responsive-design` prend le relais dès qu'il s'agit spécifiquement de mobile,
tablette, desktop et de leur cohabitation.
