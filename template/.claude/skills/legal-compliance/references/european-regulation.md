# Réglementations européennes — au-delà du RGPD

## Sous-traitants et transferts hors UE

Identifier les services externes utilisés (cloud, analytics, email, paiement, authentification,
monitoring, CRM, support, API IA, CDN, storage). Pour chaque service susceptible de traiter des
données personnelles, identifier : quelles données, pourquoi, où, qui est responsable, statut de
sous-traitant, sous-traitants ultérieurs éventuels, transfert hors UE, garanties applicables,
existence d'un contrat/DPA. Ne jamais considérer qu'une API tierce est juridiquement neutre.

Lorsqu'un transfert international est identifié : identifier le pays, le fournisseur, le
mécanisme juridique applicable (ex: clauses contractuelles types, décision d'adéquation),
les garanties, et signaler si une analyse juridique est nécessaire. Ne jamais conclure
automatiquement "le fournisseur est américain donc c'est illégal" ni "le fournisseur est connu
donc c'est conforme" — la situation dépend du service, des données, des transferts réels et du
cadre juridique applicable au moment de l'analyse.

## IA et réglementations européennes

Si le projet utilise de l'intelligence artificielle, analyser : type de système IA, finalité,
utilisateurs concernés, données utilisées, présence de décisions automatisées, profilage,
implication de données personnelles, génération de contenu, dépendance à un système/modèle
tiers. Vérifier les réglementations européennes applicables au contexte du système — ne pas se
limiter au RGPD. Le sujet étant complexe et évolutif, rechercher les sources officielles actuelles
avant de conclure et recommander une validation juridique pour tout usage à risque potentiel.

## Veille réglementaire

Les règles évoluent — ne jamais traiter les connaissances internes du Skill comme définitives sur
un sujet sensible ou évolutif. Méthode : identifier la réglementation concernée → rechercher la
source officielle actuelle → vérifier sa date → analyser l'impact sur le projet → documenter la
source (avec date/version) → signaler explicitement les incertitudes restantes.
