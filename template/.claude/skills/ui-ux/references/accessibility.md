# Accessibilité — voir le Skill dédié `accessibility`

Le détail complet des règles d'accessibilité technique (WCAG, sémantique HTML, ARIA, navigation
clavier, gestion du focus, lecteurs d'écran, contraste, mouvement, formulaires, zones tactiles) a
été déplacé vers le Skill dédié `.claude/skills/accessibility/SKILL.md` et ses `references/` —
c'est la source de vérité pour tout ce qui concerne l'accessibilité technique.

Ce Skill `ui-ux` reste responsable de la qualité UX générale (cohérence, hiérarchie visuelle,
feedback, formulaires du point de vue expérience) ; `accessibility` prend le relais dès qu'il
s'agit spécifiquement de rendre l'interface utilisable par tous, y compris au clavier ou avec un
lecteur d'écran. Voir aussi Skill `legal-compliance` → `references/accessibility.md` pour les
obligations légales, qui restent distinctes de ce Skill.
