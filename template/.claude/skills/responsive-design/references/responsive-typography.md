# Typographie responsive

La lisibilité est prioritaire sur la compacité. Vérifier : taille de texte, line-height, longueur
des lignes, titres, sous-titres, boutons, labels, messages d'erreur, textes longs.

Éviter les titres qui provoquent un overflow, des retours à la ligne inutiles qui cassent le
layout, ou une hiérarchie visuelle brisée sur petit écran. Utiliser une échelle typographique
responsive (tailles qui s'adaptent par breakpoint) quand le design system du projet le prévoit.

Ne pas réduire excessivement la taille du texte uniquement pour faire rentrer du contenu — c'est
un signe qu'il faut repenser la priorisation du contenu (voir `mobile.md`) plutôt que de sacrifier
la lisibilité.
